# 하드 워크플로 1회차: 개발·데이터 도구 실사용 개선

## 확정 범위

- 대상: 정규식, 해시, CSV, XML, JSON, URL 도구 6개
- 신규·통합 기능 3건: 정규식 치환 미리보기, 해시 일치 검증, CSV의 Markdown 표 변환
- 개별 개선 6건: 정규식 전체 찾기 플래그 정확성, 해시 입력 원본 명확화, CSV 빈 결과 보호, XML 결과 요약, JSON 입력·결과 통계, URL 쿼리 입력 라벨·세로 환경 가독성
- 공통 수정 2건: 초기화·추가 뒤 모바일 자동 포커스 방지, 복사·저장 전 결과 유무를 가까운 상태 문구로 안내

## 실행 원칙

- 별도 저가치 페이지를 만들지 않고 사용 맥락이 같은 기능을 기존 공개 도구에 통합한다.
- 각 기능은 한국어·영어, 모바일 한 열, 클립보드 차단 대체 입력, iframe 높이 동기화를 유지한다.
- 이 회차는 독립 커밋·푸시·공개 배포가 확인될 때만 완료로 기록한다.

## Skill·Markdown 효율 개선

- 한 배치를 여러 완료 회차로 나누지 못하도록 완료 증거 경계를 Skill과 결과 검증기에 추가한다.
- 기능 선택은 고정 목록으로 만들지 않고, 관찰된 문제와 기존 도구의 맥락에 맞춰 매 회차 다시 선택한다.
