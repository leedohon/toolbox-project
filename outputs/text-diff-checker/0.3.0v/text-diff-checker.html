텍스트 비교·차이 확인기

원본과 수정본을 줄 단위로 비교해 추가·삭제·변경된 내용을 한눈에 표시합니다.

  • 줄 단위 추가·삭제·동일 구분
  • 변경 수와 일치율 요약
  • 공백·대소문자 무시 선택
  • 비교 결과 복사

두 텍스트의 차이 확인하기

도구가 보이지 않으면 새 창에서 열기를 이용하세요.

사용 방법

  1. 위쪽에 원본, 아래쪽에 수정한 텍스트를 입력합니다.
  2. 필요하면 공백 또는 영문 대소문자 무시를 선택합니다.
  3. 색상으로 구분된 차이와 요약을 확인하거나 결과를 복사합니다.

텍스트 비교·차이 확인기 상세 설명

텍스트 비교·차이 확인기는 문서, 공지, 코드 조각처럼 비슷한 두 텍스트에서 바뀐 줄을 찾을 때 사용합니다. 원본에서 사라진 줄과 수정본에 추가된 줄을 구분하고, 그대로 유지된 줄도 함께 보여 전체 흐름을 놓치지 않게 합니다.

비교는 현재 브라우저 안에서만 처리됩니다. 원문과 수정문은 버튼 한 번으로 교환할 수 있고, 전체 결과나 변경된 줄만 따로 복사할 수 있습니다. 두 문서가 같으면 빈 복사 대신 가까운 상태 문구로 알려 줍니다.

비교 결과를 검토할 때 추가·삭제 줄뿐 아니라 무시 옵션도 함께 기록하세요. 대소문자나 공백을 무시하면 문장 검수에는 편리하지만 코드, 식별자, 고유명사처럼 작은 차이가 중요한 자료에서는 실제 변경을 놓칠 수 있습니다.

활용 예시

배송 안내 문구의 변경점 확인

입력
원본에 배송비는 3000원입니다.\n무료 배송 기준은 50000원입니다.를, 수정본에 배송비는 2500원입니다.\n무료 배송 기준은 50000원입니다.를 입력합니다.
결과
3000원 문장은 삭제, 2500원 문장은 추가로 표시되고 무료 배송 기준 문장은 동일한 줄로 남습니다.

대소문자와 연속 공백을 제외하고 비교

입력
원본 Release READY와 수정본 release ready를 입력하고 공백 무시와 대소문자 무시를 모두 켭니다.
결과
두 입력이 같은 한 줄로 판정되어 추가 0줄, 삭제 0줄로 표시됩니다.

결과 확인 전 알아두기

  • 비교 단위는 줄이므로 한 문장 안에서 바뀐 글자만 별도로 강조하지 않습니다.
  • 원본과 수정본은 각각 최대 500줄까지 비교할 수 있습니다.
  • 공백 또는 대소문자 무시 옵션을 켜면 그 차이가 중요한 코드와 고유명사 변경도 동일하게 처리될 수 있습니다.

자주 묻는 질문

어떤 기준으로 차이를 찾나요?

줄바꿈을 기준으로 원본과 수정본의 공통 줄을 찾고 추가·삭제된 줄을 표시합니다.

띄어쓰기 차이를 무시할 수 있나요?

네. 공백 무시를 선택하면 연속 공백과 줄 앞뒤 공백 차이를 제외하고 비교합니다.

입력한 문서가 서버로 전송되나요?

아니요. 비교와 결과 생성은 현재 브라우저 안에서만 진행됩니다.

아주 긴 문서도 비교할 수 있나요?

브라우저가 느려지는 것을 막기 위해 각 입력은 5만 자까지 지원합니다.
