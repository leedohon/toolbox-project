# 2026-08-28 하드 워크플로 3회

- 요청: 하드 워크플로를 3회 연속 수행한다.
- 각 회차는 공개 도구 6개, 사용자 개선 6건, 통합 기능 3건, 공통 수정 2건을 충족한다.
- 각 회차마다 독립 실행 기록, 릴리스, Blogger 갱신, Git 커밋·푸시, GitHub Pages 배포 확인을 완료한 뒤 다음 회차로 넘어간다.
- Skill·Markdown 최적화는 회차당 최대 1건만 근거와 대체 지표를 남긴다.
- 예약 종료와 시스템 종료는 실행하지 않는다.

## 1회차 확정 범위

- QR · 바코드 생성기: 입력 원문 텍스트 파일 불러오기와 저장 단축 동선
- JSON 도구: 현재 JSON 원문을 UTF-8 텍스트로 저장하는 동선
- 인코딩·문자 변환 도구, 비밀번호·UUID 생성기, 이미지 크기·압축·DPI 도구: 현재 선택 기능을 URL에 반영하고 이전·다음 기능 키보드 전환 제공
- 다용도 뽑기게임: 이전·다음 게임 키보드 전환과 화면 안내
- 공통 구현은 중앙 자산에서 처리하고 모바일 입력 중 오작동을 막는다.

## 종료 정책

- 예약 종료 없음
- 시스템 종료 없음

## 2회차 확정 범위

- CSS 디자인, 텍스트 비교, 마크다운, CSV, 정규식, 해시 도구에 `Alt + R` 초기화 단축키와 다국어 안내를 공통 적용한다.
- 텍스트 비교 원문·수정문, 마크다운 원문, 정규식 테스트 문장을 UTF-8 파일로 저장한다.
- 기존 초기화 버튼과 자동 생성 초기화 버튼은 같은 단축키 계약과 모바일 안전 포커스를 사용한다.

## 3회차 확정 범위

- 이미지 모자이크, 다용도 계산기, 텍스트 정리, JWT, XML, URL 도구에 `Alt + R` 초기화 단축키를 공통 적용한다.
- 이미지 모자이크 PNG, 텍스트 정리 TXT, XML 결과 파일은 `Ctrl/⌘ + Shift + S`로 저장할 수 있게 한다.
- 실행·초기화·저장 단축키 안내는 공통 자산 하나에서 조합하고 KOR / ENG 변경을 함께 반영한다.
