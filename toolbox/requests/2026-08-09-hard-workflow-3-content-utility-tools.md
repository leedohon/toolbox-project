# 하드 워크플로 2회차: 콘텐츠·생활 도구

- 대상: `base64-tools`, `image-mosaic-tool`, `date-calculator`, `color-converter-contrast`, `text-counter-cleaner`, `markdown-preview-converter`
- 버전: 각 도구 `minor`
- 공개: 기존 Blogger 게시글 갱신, `main` 독립 커밋·푸시, Pages 공개 확인
- 종료 예약: 사용하지 않음

## 확정 구현

1. Base64 입력을 표준 형식으로 정규화하는 빠른 동작을 추가한다.
2. 이미지 모자이크에 한 단계 다시 실행과 `Ctrl/Cmd + Shift + Z`를 추가한다.
3. 다용도 계산기에 생년월일 기준 만 나이 계산을 통합한다.
4. CSS 디자인 도구에 현재 배경에서 대비가 더 높은 흑백 글자색 추천을 추가한다.
5. 텍스트 도구에 자주 나온 단어 상위 5개를 실시간 표시한다.
6. 마크다운 도구에 문서 제목 목차와 목차 복사를 추가한다.

## 공통 수정

- 입력이 바뀌면 이전 복사 대체 영역과 오래된 완료 상태를 즉시 정리한다.
- 변경한 엔진의 허브 캐시 키와 KOR/ENG 접근성 이름을 함께 갱신한다.

## 페이지 작업 집계

- Base64 정규화, 만 나이 계산, 마크다운 목차를 기존 유용한 도구 안에 통합한 기능 3건으로 집계한다.
- 단독 페이지를 늘리지 않고 기존 공개 주소와 은퇴 도구 호환 진입점은 유지한다.
