사용 방법

  1. 두 좌표 계산 또는 좌표 표기 변환을 선택합니다.
  2. 선택한 모드에 표시되는 위도·경도 값을 입력합니다.
  3. 거리·방향·중간점 또는 변환된 좌표를 확인합니다.

좌표·거리 계산기 상세 설명

좌표·거리 계산기는 십진수 위도·경도를 도·분·초 표기로 바꾸거나 반대로 변환합니다. 두 지점의 대권거리·초기 방위각·중간점을 계산하며 출발과 도착 좌표를 버튼 한 번으로 교환할 수 있습니다.

거리 결과는 직선에 가까운 지표면 최단 경로의 근사값이며 도로·철도·항공 실제 이동 거리나 정밀 측량값이 아닙니다. 좌표 범위와 분·초 값을 검증하고 모든 계산은 현재 브라우저 안에서만 수행합니다.

활용 예시

서울에서 부산까지 대권거리 확인

입력
출발 좌표 37.5665, 126.9780과 도착 좌표 35.1796, 129.0756을 입력합니다.
결과
약 325km의 대권거리와 초기 방위각, 나침반 방향, 두 지점의 중간점이 표시됩니다.

십진 위도를 도·분·초로 변환

입력
십진 좌표 37.5665와 위도 축을 선택합니다.
결과
북위 기준의 도·분·초 표기가 표시되며 결과를 복사할 수 있습니다.

결과 확인 전 알아두기

  • 거리는 지구를 구면으로 본 대권거리 근사값이며 도로·철도·항공 실제 이동 거리와 다릅니다.
  • 초기 방위각은 출발점 기준이며 이동 경로 전체에서 같은 방향을 유지한다는 뜻이 아닙니다.
  • 정밀 측량, 법적 경계나 안전 운항 판단에는 전문 좌표계와 검증된 측량 자료를 사용해야 합니다.

자주 묻는 질문

거리 결과는 도로 이동 거리인가요?

아니요. 두 좌표 사이의 대권거리를 계산하므로 실제 도로 경로와 다릅니다.

음수 좌표는 어떤 방향인가요?

위도 음수는 남위, 경도 음수는 서경으로 변환합니다.

방위각은 어느 지점을 기준으로 하나요?

출발 좌표에서 도착 좌표를 향한 초기 방위각을 북쪽 0도 기준으로 표시합니다.

도·분·초에서 분과 초의 범위는 무엇인가요?

분과 초는 각각 0 이상 60 미만이어야 합니다.

좌표가 외부 지도 서비스로 전송되나요?

아니요. 모든 변환과 계산은 현재 브라우저 안에서만 수행됩니다.
