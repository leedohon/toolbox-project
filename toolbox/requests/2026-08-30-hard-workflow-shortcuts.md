## 실행 조건

- 5시간 사용량은 인증되지 않아 확인할 수 없었으며 값을 추정하지 않는다.
- 현재 자동화 규칙에 따라 `unavailable`은 경고 후 진행하고, 확인된 잔여 비율이 20% 미만일 때만 건너뛴다.
- 시스템 종료와 예약 종료는 설정하지 않는다.

## 확정 범위

- 개발자 빠른 참조, 대출·저축, 좌표·거리 도구는 `Alt + S`로 대표 예제를 적용한다.
- 텍스트 추출, 웹 메타, IP·네트워크 도구는 `Ctrl/⌘ + Shift + C`로 현재 결과를 복사한다.
- 공통 자산 하나에서 단축키 동작, `aria-keyshortcuts`, KOR / ENG 안내를 처리한다.
- 각 도구는 minor 버전으로 릴리스하고 Blogger 게시글, 카탈로그, GitHub Pages를 함께 갱신한다.
