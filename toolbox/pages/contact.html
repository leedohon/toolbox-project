문의하기

도구 오류, 모바일 화면 문제, 설명 수정과 기능 제안을 확인할 수 있도록 필요한 정보를 간단히 안내합니다.

가장 빠른 문의 방법

문제가 발생한 도구 게시글의 댓글에 도구 이름과 증상을 남겨 주세요. 저장소 작업을 확인할 수 있는 경우에는 GitHub 공개 이슈로도 제보할 수 있습니다.

계정 정보, 비밀번호, 개인 문서 원문, 금융 정보와 같은 민감한 내용은 댓글이나 공개 이슈에 적지 마세요.

오류를 알려 주실 때

  • 사용한 도구 이름과 선택한 기능
  • 어떤 순서로 조작했을 때 문제가 생겼는지
  • 기대한 결과와 실제로 표시된 결과
  • 모바일 또는 PC 여부와 브라우저 종류
  • 개인정보를 가린 화면 캡처 또는 짧은 예시 입력

기능 제안 기준

여러 사람이 반복해서 겪는 불편을 줄이고, 기존 도구와 같은 입력 흐름으로 자연스럽게 합칠 수 있는 기능을 우선 검토합니다. 한 번의 단순 계산만 제공하거나 이미 있는 기능을 이름만 바꾼 제안은 기존 도구의 모드나 안내 개선으로 처리할 수 있습니다.

답변과 처리

모든 문의에 개별 답변이나 일정 확정을 보장하지는 않지만, 재현 가능한 오류와 접근성·모바일 사용 문제는 우선 확인합니다. 수정된 내용은 해당 도구 게시글의 패치노트에서 확인할 수 있습니다.
