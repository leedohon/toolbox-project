JWT 내용 확인기

JWT의 헤더와 페이로드를 서명 검증 없이 브라우저에서 읽기 좋게 확인합니다.

  • Base64URL 디코딩
  • 헤더·페이로드 JSON
  • exp·iat 시간 안내
  • 서명 미검증 경고

JWT 내용 열기

도구가 보이지 않으면 새 창에서 열기를 이용하세요.

사용 방법

  1. 점으로 구분된 JWT 문자열을 붙여넣습니다.
  2. 헤더와 페이로드 내용을 확인합니다.
  3. 필요한 JSON만 복사하고 민감한 토큰은 공유하지 않습니다.

JWT 내용 확인기 상세 설명

JWT 내용 확인기는 토큰의 앞 두 구간을 Base64URL 방식으로 풀어 헤더와 페이로드 JSON을 보여 줍니다. 두 JSON을 각각 복사하거나 하나의 JSON 파일로 저장할 수 있고 exp·iat·nbf 시각, 알고리즘, 발급자, 주체, 대상과 토큰 ID를 따로 요약합니다.

이 도구는 서명을 검증하지 않으므로 표시된 내용을 신뢰성 증명으로 사용하면 안 됩니다. 토큰은 현재 브라우저에서만 처리하지만 실제 접근 권한이 담긴 토큰은 공개 장소나 공유 컴퓨터에 붙여넣지 마세요.

표시된 만료 시각과 클레임은 디버깅 참고용으로만 사용하세요. 토큰을 신뢰하려면 발급자, 대상, 서명 알고리즘과 공개키를 서버에서 검증해야 하며, 디코딩 화면만으로 접근 권한이나 위조 여부를 판정해서는 안 됩니다.

활용 예시

JWT의 사용자 정보를 JSON으로 확인

입력
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjMiLCJuYW1lIjoiS2ltIn0.x를 입력합니다.
결과
헤더의 alg HS256·typ JWT와 페이로드의 sub 123·name Kim이 각각 읽기 좋은 JSON으로 표시됩니다.

토큰의 발급·만료 시각 읽기

입력
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJleHAiOjE3NjcyMjU2MDAsImlhdCI6MTczNTY4OTYwMH0.x를 입력합니다.
결과
iat와 exp 숫자가 브라우저의 현지 시각으로 변환되고 exp 값이 현재 기준으로 만료되었는지 안내됩니다.

결과 확인 전 알아두기

  • 헤더와 페이로드만 디코딩하며 서명, 발급자, 대상 서비스와 토큰 위조 여부는 검증하지 않습니다.
  • 실제 접근 토큰에는 개인정보와 권한 정보가 있을 수 있으므로 공유 컴퓨터나 상담 메시지에 붙여 넣지 않아야 합니다.
  • 점으로 구분된 세 구간과 JSON 형식의 헤더·페이로드를 가진 최대 20,000자 JWT만 처리합니다.

자주 묻는 질문

이 도구가 JWT 서명을 검증하나요?

아니요. 내용을 디코딩해 보여 줄 뿐이며 위조 여부나 발급자를 검증하지 않습니다.

토큰이 서버로 전송되나요?

아니요. 입력은 현재 브라우저 안에서만 처리합니다.

점이 세 구간보다 많은 토큰도 되나요?

이 도구는 일반적인 세 구간 JWS 형태의 JWT에 맞춰져 있습니다.

exp 시간이 지났다는 표시는 무엇인가요?

현재 시각이 exp 값보다 뒤라면 만료된 것으로 안내하지만 실제 서버 정책을 대신하지는 않습니다.
