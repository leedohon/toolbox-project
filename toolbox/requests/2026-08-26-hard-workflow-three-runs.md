# 하드 워크플로 3회

- 요청: 하드 워크플로를 독립 증거 단위로 3회 연속 실행한다.
- 각 회차: 공개 도구 6개 개선, 실사용 통합 기능 3건, 둘 이상의 대상에 적용되는 공통 UX 수정 2건을 완료한다.
- 공개 처리: 회차별 Blogger 갱신, 독립 Git 커밋·푸시, GitHub Pages 배포 확인까지 완료한다.
- 효율 처리: 회차마다 Skill·Markdown 중복을 점검하고, 실제 토큰이 제공되지 않으면 검증 가능한 대체 지표만 기록한다.
- 종료 예약: 요청하지 않았으므로 설정하지 않는다.

## 공통 구현 방향

- 입력 중심 도구에 키보드 실행 단축키와 안전한 입력 초기화를 점진적으로 제공한다.
- 장문 텍스트 도구에는 브라우저 안에서 처리되는 텍스트 파일 불러오기를 제공한다.
- 모바일에서는 불러오기·초기화 뒤 입력 요소를 자동 포커스하지 않는다.
