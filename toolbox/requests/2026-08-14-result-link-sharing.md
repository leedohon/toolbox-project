# 뽑기게임 결과 링크 공유

## 사용자 요청

- Discord 같은 메신저에 URL을 보내면, 상대가 링크를 열었을 때 Blogger의 다용도 뽑기게임 글에서 같은 결과를 즉시 확인할 수 있게 한다.
- 기존 결과 코드 복사와 PNG 저장은 링크가 너무 길거나 클립보드 복사가 막힌 경우를 위한 보조 수단으로 유지한다.

## 확정 구현

- 사다리, 돌림판, 숫자뽑기와 편가르기에 `결과 링크 복사`를 공통 제공한다.
- 공유 주소는 다용도 뽑기게임 Blogger 게시글을 기준으로 만들고 `#tb-mode=...&tb-result=...`에 게임 모드와 기존 `TB1-` 결과 코드를 담는다.
- Blogger 전역 스크립트가 공유 조각을 검증한 뒤 통합 도구 iframe에 전달하고, 통합 도구는 일치하는 게임 모듈만 먼저 연다.
- 게임 모듈은 기존 결과 코드 검증을 그대로 거쳐 입력과 확정 결과를 자동 복원한다. 손상되거나 다른 도구의 코드는 실행하지 않고 가까운 상태 영역에서 안내한다.
- 자동 복원 후 결과 위치가 보이도록 중첩 iframe과 Blogger 사이에 검증된 스크롤 위치 메시지를 전달한다.
- 공유 URL은 메신저 전송을 고려해 1,900자 이하로 제한한다. 초과하면 결과 코드 또는 PNG 사용을 안내한다.
- 결과는 서버에 저장하지 않는다. 다만 URL을 받은 사람과 메신저 서비스는 조각에 담긴 결과 코드를 볼 수 있으므로 이름·후보가 포함될 수 있다는 기존 개인정보 안내를 유지한다.

## 호환성

- 기존 `TB1-` 결과 코드 형식, 기존 결과 코드 붙여넣기, PNG 저장과 단독 게임 주소를 보존한다.
- `#ow-tool-search`와 일반 블로그 주소는 기존대로 동작한다.
- 통합 도구의 기존 `mode` URL과 브라우저 선택 기억을 유지한다.

## 검증

- 네 게임에서 링크 생성 → Blogger 주소 해석 → 올바른 모드 선택 → 같은 결과 자동 복원을 확인한다.
- 손상 코드, 다른 게임 코드, 1,900자 초과 링크를 거부하고 대체 안내를 표시한다.
- 클립보드 차단 시 수동 복사 영역이 나타나며 모바일에서 자동 포커스하지 않는지 확인한다.
- 375px·1280px에서 버튼 줄바꿈, 가로 넘침, iframe 높이 증가·감소와 결과 이동을 확인한다.
- 회귀 증거: `HUB_STORAGE_ACCESS_BLOCKED`, `HUB_PRELOAD_STATUS_MISMATCH`, `IFRAME_HEIGHT_STALE`, `IFRAME_HEIGHT_CAP_MISMATCH`, `SHARED_ASSET_CACHE_STALE`.
