사용 방법

  1. 이미지 변환 또는 DPI·PPI 계산 모드를 선택합니다.

  3. 변환 이미지를 저장하거나 계산 결과를 확인합니다.

이미지 크기·압축·DPI 도구 상세 설명

이미지 크기·압축·DPI 도구는 사진의 픽셀 크기와 저장 용량을 줄이는 변환 모드, 픽셀 수와 실제 출력 크기로 DPI·PPI를 계산하는 해상도 모드를 한곳에 모았습니다. 웹 게시용 최적화와 인쇄용 해상도 확인을 같은 화면에서 이어서 처리할 수 있습니다.

이미지 변환은 비율 프리셋과 긴 변 1280px·1920px 프리셋 또는 직접 입력으로 크기를 정하고 PNG·JPEG·WebP 형식과 품질을 조절합니다. 저장 파일명을 직접 정하면 선택한 형식의 확장자가 자동으로 붙고, 설정을 바꾸면 이전 결과를 바로 숨겨 잘못된 파일 저장을 막습니다.

파일 읽기, 미리보기, 변환과 계산은 모두 현재 브라우저 안에서 실행되며 이미지가 서버로 업로드되지 않습니다. 지원하지 않는 파일이거나 크기·출력 단위 값이 올바르지 않으면 안내를 확인해 파일을 다시 선택하거나 숫자를 수정한 뒤 실행하세요.

용도에 따라 픽셀 크기, 파일 형식, 품질을 함께 결정하세요. 웹 게시용은 실제 표시 폭에 맞춘 WebP가 유리할 수 있지만, 투명 배경이나 반복 편집이 필요하면 PNG 등 원본 특성을 유지하는 형식이 더 적합합니다.

결과 확인 전 알아두기

  • 이미지 파일은 20MB 이하이며 입력·출력 모두 한 변 8,000px, 전체 3,200만 픽셀 이하만 처리합니다.
  • 같은 품질 값이라도 사진 내용과 브라우저의 인코더에 따라 실제 출력 용량이 달라질 수 있습니다.
  • DPI·PPI 계산은 픽셀과 출력 크기의 수치 관계를 보여 줄 뿐 파일의 DPI 메타데이터나 프린터 설정을 변경하지 않습니다.

자주 묻는 질문

이미지 변환과 DPI·PPI 계산은 어떻게 선택하나요?

화면 위쪽에서 크기·용량 변환 또는 해상도 계산 모드를 선택하면 해당 기능에 필요한 입력만 표시됩니다.

어떤 이미지 형식을 지원하나요?

PNG, JPEG와 WebP 입력·출력을 지원하며 JPEG와 WebP는 품질을 조절할 수 있습니다. 저장 파일명은 직접 입력하고 확장자는 선택한 형식에 맞게 자동 적용됩니다.

DPI와 PPI 계산에는 어떤 값이 필요한가요?

이미지의 가로·세로 픽셀과 실제 출력할 가로·세로 크기, inch 또는 cm 단위가 필요합니다.

결과 용량이 커지거나 계산 오류가 나오면 어떻게 하나요?

이미지는 픽셀 크기나 품질을 낮추고 JPEG·WebP를 선택해 보세요. 해상도 계산은 0보다 큰 픽셀·출력 크기를 입력한 뒤 다시 계산하세요.

이미지가 서버로 업로드되나요?

아니요. 파일 읽기, 크기 변경, 저장 파일 생성과 DPI·PPI 계산은 현재 브라우저 안에서만 처리합니다.
