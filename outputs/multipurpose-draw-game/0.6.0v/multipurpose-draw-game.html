사용 방법

  1. 사다리, 돌림판, 숫자뽑기 또는 편가르기를 선택합니다.
  2. 참가자·항목·숫자 범위처럼 선택한 게임의 값을 입력합니다.
  3. 결과를 확인하고 필요하면 결과 코드나 PNG로 공유합니다.

다용도 뽑기게임 상세 설명

다용도 뽑기게임은 사다리, 돌림판, 숫자뽑기와 편가르기를 한 게시글에서 골라 쓰는 브라우저 놀이 도구입니다. 모임 순서, 메뉴, 번호, 역할과 팀을 정할 때 필요한 방식만 선택하면 별도 페이지를 찾아 이동하지 않아도 됩니다.

각 모드는 기존 입력 방식과 결과 기능을 그대로 유지합니다. 모드 선택은 클릭·터치뿐 아니라 방향키와 Home·End 키로도 이동할 수 있고, 결과 코드를 복사해 같은 결과를 다시 열거나 PNG 이미지로 저장할 수 있습니다.

게임을 바꿔도 이미 입력한 내용과 결과는 현재 화면에서 유지됩니다. 선택한 게임은 주소에도 반영되어 같은 주소를 다시 열면 해당 모드에서 시작하며 기존 결과 코드도 계속 사용할 수 있습니다.

모든 입력과 무작위 처리는 현재 브라우저 안에서 실행됩니다. 이름, 후보와 결과를 별도 서버에 저장하지 않으며 KOR / ENG 화면을 지원합니다.

참가자 목록을 확정한 뒤 결과 코드를 함께 보관하면 같은 입력과 결과를 다시 확인할 수 있습니다. 다만 이 결과는 오락·간단한 순서 정하기에 적합하며 추첨의 법적 공정성이나 외부 감사 증빙을 대신하지 않습니다.

결과 확인 전 알아두기

  • 브라우저에서 만든 무작위 결과이므로 법적 추첨, 경품 당첨이나 감사 가능한 공식 배정의 증빙으로 사용할 수 없습니다.
  • 결과는 입력 항목과 선택한 모드·설정에 따라 달라지며 이전 결과를 복원하려면 결과 코드를 따로 보관해야 합니다.
  • 참가자 자격, 항목별 가중치의 타당성이나 팀 구성의 실력 균형까지 판단하지 않습니다.

자주 묻는 질문

어떤 게임을 사용할 수 있나요?

사다리, 돌림판, 숫자뽑기와 편가르기 네 가지를 한 화면에서 선택할 수 있습니다.

게임을 바꾸면 입력한 내용이 사라지나요?

아니요. 같은 화면을 닫거나 새로고침하기 전까지 각 게임의 입력과 결과가 유지됩니다.

예전에 받은 결과 코드도 사용할 수 있나요?

네. 코드를 만든 게임 모드를 선택한 뒤 결과 코드 입력란에 붙여 넣으면 기존 결과를 다시 열 수 있습니다.

편가르기는 몇 팀까지 지원하나요?

참가자 수 안에서 2개부터 최대 10개 팀까지 최대한 균등하게 나눌 수 있습니다.

결과를 다른 사람에게 보낼 수 있나요?

각 게임에서 결과 코드를 복사하거나 결과 화면을 PNG로 저장해 공유할 수 있습니다.

입력한 이름이나 후보가 서버에 저장되나요?

아니요. 입력, 추첨과 결과 생성은 현재 브라우저 안에서만 처리됩니다.
