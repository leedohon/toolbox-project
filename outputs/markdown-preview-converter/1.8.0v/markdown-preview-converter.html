마크다운 작성 도구

마크다운 문서를 미리 보고 HTML로 변환하거나 행·열 데이터로 표 문법을 빠르게 만드세요.

  • 마크다운 실시간 미리보기
  • 안전한 HTML 변환·저장
  • 행·열 기반 표 문법 생성
  • 결과 복사와 KOR / ENG

마크다운 문서 또는 표 만들기

도구가 보이지 않으면 새 창에서 열기를 이용하세요.

사용 방법

  1. 문서 미리보기·HTML 변환 또는 표 생성 모드를 선택합니다.
  2. 마크다운 문서나 표의 머리글·행 데이터를 입력합니다.
  3. 미리보기와 결과 문법을 확인한 뒤 복사하거나 저장합니다.

마크다운 작성 도구 상세 설명

마크다운 작성 도구는 문서를 실시간으로 미리 보고 안전한 HTML로 변환하는 모드와 행·열 데이터를 마크다운 표 문법으로 만드는 모드를 한곳에 통합했습니다. README, 블로그 초안과 표가 포함된 문서를 작성할 때 필요한 기능을 선택해 결과를 바로 복사하거나 저장할 수 있습니다.

미리보기 모드는 제목, 강조, 링크, 인용, 목록과 코드 블록을 변환하고 단어 수·예상 읽기 시간·제목·링크 수와 제목 단계 기반 목차로 문서 구조를 보여 줍니다. 목차는 텍스트로 바로 복사할 수 있으며, 표 생성 모드는 머리글과 행 데이터를 받아 마크다운 표를 만듭니다.

입력한 원문과 표 데이터는 현재 브라우저 안에서만 처리되며 서버로 전송되지 않습니다. 열 개수가 맞지 않거나 빈 항목이 있으면 표시된 행을 고쳐 다시 생성할 수 있고, 복사가 차단되면 대체 결과를 직접 선택하거나 HTML 파일로 저장할 수 있습니다.

변환 결과를 다른 서비스에 붙여 넣기 전에는 해당 서비스가 지원하는 Markdown 범위를 확인하세요. 표, 체크박스, 각주 같은 확장 문법은 플랫폼마다 다르므로 미리보기와 최종 게시 화면을 한 번 더 비교하는 것이 좋습니다.

#초간단툴박스#무료온라인도구#웹도구#마크다운#MarkdownPreview#HTML변환#마크다운표#문서도구

활용 예시

간단한 작업 목록을 HTML로 변환

입력
# 배포 일정\n- 검수\n- 공개를 입력합니다.
결과
<h1>배포 일정</h1>과 검수·공개 항목을 담은 <ul> 목록 HTML이 생성되고 미리보기에 바로 반영됩니다.

점수표 마크다운 문법 만들기

입력
머리글에 이름, 점수, 행 데이터에 민수, 92\n지수, 88을 입력합니다.
결과
2개 열과 2개 데이터 행을 가진 파이프(|) 형식의 마크다운 표 문법이 생성됩니다.

결과 확인 전 알아두기

  • 미리보기 변환기는 제목, 목록, 인용, 코드와 링크 등 지원하는 공통 문법만 처리하며 플랫폼별 확장 문법은 다르게 보일 수 있습니다.
  • 원시 HTML은 실행하지 않고 문자로 이스케이프하며 http, https, mailto가 아닌 링크 주소는 안전한 대체 주소로 바꿉니다.
  • 미리보기 입력은 최대 50,000자이므로 매우 긴 문서는 구간을 나누어 확인해야 합니다.

자주 묻는 질문

어떤 마크다운 기능을 지원하나요?

문서 미리보기·안전한 HTML 변환과 행·열 데이터를 이용한 마크다운 표 생성을 지원합니다.

미리보기에서 어떤 문법을 사용할 수 있나요?

제목, 굵게, 기울임, 링크, 인라인 코드, 코드 블록, 인용문과 순서·비순서 목록을 지원합니다.

마크다운 표의 열 개수가 맞지 않으면 어떻게 하나요?

머리글과 각 행의 항목 수를 같게 맞추고 빈 셀을 확인한 뒤 다시 생성하세요. 오류가 난 행은 가까운 위치에서 안내합니다.

HTML 태그나 스크립트가 실행되나요?

직접 입력한 HTML은 실행하지 않고 코드로 처리하며 변환기가 생성한 제한된 안전 태그만 미리보기에 사용합니다.

입력한 문서와 표가 서버에 저장되나요?

아니요. 미리보기, HTML 변환과 표 생성은 현재 브라우저 안에서만 진행됩니다.

복사가 되지 않을 때 결과를 어떻게 가져오나요?

자동 복사가 차단되면 화면의 대체 결과를 직접 선택하세요. HTML 변환 결과는 파일로 저장할 수도 있습니다.
