# 하드 워크플로: 입력 복귀 동선

- 실행 ID: `20260831-013236-hard`
- 대상: CSS 디자인, 텍스트 비교, 마크다운, CSV, 정규식, 해시 도구
- 목표: 긴 결과나 미리보기를 확인한 뒤 첫 입력 또는 도구 선택으로 즉시 돌아갈 수 있게 한다.
- 공통 적용 1: 여섯 대상에 입력·설정 복귀 버튼을 제공한다.
- 공통 적용 2: 같은 동작을 `Alt + U`로 실행하고 `aria-keyshortcuts`에 공개한다.
- 페이지 작업: CSS·마크다운 허브의 모듈 선택 복귀, 텍스트 비교의 원본 입력 복귀를 독립 검증한다.
- 안전: 모바일 자동 포커스는 사용자 동작 없이 실행하지 않으며 삭제·휴지통·초안 전환을 하지 않는다.
