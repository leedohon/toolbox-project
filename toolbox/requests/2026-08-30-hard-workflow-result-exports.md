2. 복사·저장 동작의 키보드 계약을 여섯 도구의 실제 결과 동작에 연결한다.
3. CSS 디자인 도구는 현재 색상 조합의 CSS 파일을 저장한다.
4. 텍스트 비교 도구는 비교 요약을 별도로 복사한다.
5. 마크다운 작성 도구는 문서 목차를 TXT 파일로 저장한다.
6. CSV 변환기는 현재 열 이름을 복사하고 세미콜론 예제의 잘못된 구분자 선택을 수정한다.
7. 정규식 도구는 위치와 캡처 그룹을 포함한 JSON 결과를 복사한다.
8. 해시 생성기는 선택한 단일 알고리즘의 SRI 값을 복사한다.
