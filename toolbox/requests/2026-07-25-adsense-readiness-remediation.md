# 2026-07-25 AdSense 수익화 준비 개선

## 사용자 요청

- 수익이 발생하지 않는 원인을 확인한 결과에 따라 차단 요소부터 순서대로 처리한다.
- 예약 종료는 사용자가 별도 명령으로 요청한 경우에만 실행하며, 이번 작업에서는 설정하지 않는다.
- 기존에 준비 중인 신규 도구 5개는 수익화 준비보다 앞서 공개하지 않고 현재 작업 상태를 보존한다.

## 확인된 원인

- AdSense 사이트 검토 상태는 `광고 게재가 준비되지 않은 사이트`이며, 주요 사유는 `가치가 별로 없는 콘텐츠`와 `게시자 콘텐츠가 없는 화면에 Google 게재 광고`다.
- 공개 Blogger 글 51개 중 통합 후 전환 안내만 남은 글이 32개라서 저가치·중복 성격의 글이 전체의 약 63%를 차지한다.
- 광고 스크립트가 실제 활성 게시글뿐 아니라 홈·검색·라벨·보관함 같은 비콘텐츠 화면에서도 실행될 수 있다.
- 활성 도구의 실행 화면은 GitHub Pages iframe에 있고, 저장소 루트 전체가 Pages로 배포되어 실행 전용·버전 보관 HTML까지 검색 대상이 될 수 있다.
- 개인정보 처리방침, 소개, 문의 같은 기본 신뢰 페이지가 없다.
- 최근 7일 Blogger 조회수는 있었지만 AdSense 페이지뷰·노출·클릭은 모두 0이다. 현재의 직접 원인은 트래픽 부족보다 사이트 승인 실패다.

## 처리 순서

1. 전환 안내 글 32개는 삭제·초안 전환·리디렉션하지 않고 기존 공개 주소와 호환 안내를 유지한다.
2. 전환 안내 글에 `toolbox-retired` 기계 판독 라벨을 붙이고 `noindex,follow`를 적용한다. 홈·검색·라벨·보관함 목록에서는 숨기며 광고를 싣지 않는다.
3. 광고 노출은 실제 활성 게시글 화면으로 제한하고 홈·검색·라벨·보관함·오류·신뢰 페이지에서는 실행하지 않는다.
4. 실행 전용 GitHub Pages 문서에는 `noindex`를 적용하고, 공개 배포 산출물에서는 내부 작업·버전 보관 HTML을 제외한다.
5. 활성 게시글은 현재의 상세 설명·사용 방법·FAQ 외에 구체적인 입력 예시, 결과 해석, 한계와 주의사항을 보강한다.
6. 개인정보 처리방침, 사이트 소개, 문의 페이지를 만들고 공통 하단에서 연결한다.
7. 모바일·데스크톱 레이아웃, 색인 메타, 광고 범위, JSON·릴리스 구조를 공개 URL에서 다시 검증한다.
8. 실제 공개 상태에서 모든 수정이 확인된 뒤에만 AdSense 재검토 준비 상태를 보고한다. 재검토 제출 자체는 별도 승인 없이 실행하지 않는다.

## 안전 경계

- 공개 글을 삭제하거나 휴지통으로 이동하거나 초안으로 되돌리지 않는다.
- 기존 주소의 사용자 호환성을 유지한다. 글 삭제가 전제되는 맞춤 리디렉션은 이번 단계에서 적용하지 않는다.
- 과거 버전 폴더는 수정하지 않고, 활성 게시글 본문이 바뀌는 경우 새 `minimum` 버전을 만든다.
- 광고 계정 설정, Blogger 게시글·페이지·테마 수정, Git 푸시와 공개 배포처럼 외부 상태를 바꾸는 작업은 정확한 대상을 확인한 뒤 승인 범위 안에서만 실행한다.
- 실제 개발 토큰 수가 제공되지 않으므로 전체 토큰 감소율은 확정하지 않고 `proxy_only` 지표만 기록한다.

## 2026-08-03 공개 반영 결과

- 활성 게시글 19개는 최신 설명·예시·제한 안내로 갱신했다.
- 은퇴 게시글 32개는 삭제하지 않고 실제 대체 도구를 가리키는 호환 안내와 `toolbox-retired` 라벨로 갱신했다.
- 문의, 사이트 소개, 개인정보 처리방침 페이지를 공개하고 `outputs/site.json`의 공통 링크에 연결했다.
- Blogger API가 정적 페이지 쓰기 권한을 거부해 페이지 3개는 로그인된 Blogger 관리자 화면에서 같은 원본 HTML로 게시했다.
- 업로드 직전 실제 테마와 보관본의 차이는 Blogger navbar `origin` 자동 생성값뿐임을 확인한 뒤, 광고 위젯·인라인 광고 렌더링을 제거하고 은퇴 글 목록 제외·`noindex,follow`를 적용한 테마를 업로드했다.
- AdSense 홈의 사이트 미리보기 설정에서 `bloggiedh.blogspot.com` 자동 광고를 껐고, 다시 연 설정 화면에서 스위치가 꺼짐으로 저장된 것을 확인했다. 다만 Blogger 공개 원문에는 반영 지연 안내 시간 안에 기존 `adsenseAutoAds: true` 값이 남아 있어 공개 검사에서 계속 추적하며, 재검토는 제출하지 않았다.
- Blogger가 테마 업로드 뒤에도 기존 레이아웃 상태를 보존해 다시 나타난 `추천 게시물`과 `인기 글` 위젯을 관리자 레이아웃에서 직접 삭제했다. 데스크톱·모바일 공개 글에서 두 위젯이 모두 사라진 것을 다시 확인했다.
- 준비 중인 신규 도구 5개는 소스와 릴리스를 보존하되 공개 카탈로그와 Pages 배포 산출물에서는 제외했다.
- 예약 종료와 시스템 종료는 실행하지 않았다.
