이미지 모자이크 도구

사진에서 얼굴, 이름, 번호처럼 숨기고 싶은 부분을 브러시로 칠하거나 사각형으로 선택해 모자이크 처리하세요.

  • 파일 선택과 드래그 앤 드롭
  • 브러시 칠하기·사각형 범위 선택
  • 모자이크 강도 조절과 선택 범위 미리보기
  • 되돌리기·초기화·PNG 저장
  • KOR / ENG 화면 전환

이미지 모자이크 하기

도구가 보이지 않으면 새 창에서 열기를 이용하세요.

사용 방법

  1. PNG, JPEG 또는 WebP 이미지를 선택하거나 드롭합니다.
  2. 브러시 또는 사각형 선택을 고르고 모자이크 강도를 조절합니다.
  3. 브러시로 숨길 부분을 칠하거나 시작점부터 끝점까지 사각형으로 드래그합니다.
  4. 결과를 확인한 뒤 PNG 파일로 저장합니다.

이미지 모자이크 도구 상세 설명

이미지 모자이크 도구는 사진의 얼굴, 차량 번호, 문서의 개인정보처럼 공개하고 싶지 않은 부분을 브라우저에서 가릴 때 사용합니다. 자유롭게 칠하거나 사각형 범위를 지정해 필요한 위치만 처리할 수 있습니다.

모자이크 강도를 조절하고 현재 편집 단계 수를 보면서 되돌리거나 다시 실행할 수 있으며 결과는 원하는 파일명의 PNG로 저장합니다. 원본 비교 버튼은 편집 단계를 보존한 채 가리기 전 이미지와 현재 편집본을 번갈아 보여 줍니다.

저장 전 확대 화면에서 선택 영역의 가장자리와 빠진 부분을 확인하고, 저장한 PNG도 다시 열어 가림 상태를 점검하세요. 개인정보 보호가 중요한 이미지는 모자이크 강도를 낮게 두기보다 원문을 알아볼 수 없는 수준으로 적용해야 합니다.

활용 예시

자동차 번호판을 사각형으로 가리기

입력
JPEG 사진을 불러오고 사각형 선택 모드에서 번호판 전체를 드래그한 뒤 모자이크 강도를 조절합니다.
결과
선택 범위 전체에 균일한 모자이크가 적용되고 나머지 사진은 유지된 PNG를 저장할 수 있습니다.

문서 사진의 이름만 브러시로 숨기기

입력
문서 이미지를 불러와 브러시 크기를 이름 높이에 맞춘 뒤 글자 위를 칠합니다.
결과
칠한 경로만 모자이크 처리되며 범위를 잘못 그렸다면 한 단계 되돌린 뒤 다시 적용할 수 있습니다.

결과 확인 전 알아두기

  • 입력 파일은 15MB 이하, 한 변은 5,000px 이하, 전체는 2,000만 픽셀 이하여야 합니다.
  • 얼굴, 번호판이나 개인정보 영역을 자동으로 찾지 않으므로 사용자가 직접 가릴 범위를 선택해야 합니다.
  • 되돌리기 이력은 브러시와 사각형 작업을 합해 최대 100단계이며 페이지를 닫으면 편집 상태가 사라집니다.

자주 묻는 질문

이미지가 서버로 업로드되나요?

아니요. 이미지 불러오기, 모자이크 처리, 저장은 모두 현재 브라우저 안에서 진행됩니다.

자유 칠하기와 사각형 선택은 어떻게 다른가요?

자유 칠하기는 손가락이나 마우스로 지나간 부분을 처리하고, 사각형 선택은 드래그 시작점과 종료점 사이의 네모 영역 전체를 한 번에 처리합니다.

모자이크를 잘못 적용했다면 어떻게 하나요?

한 단계 되돌리기와 다시 실행 버튼 또는 단축키로 편집 단계를 오갈 수 있습니다. 원본 비교 버튼을 누르면 편집을 잃지 않고 가리기 전후도 확인할 수 있습니다.

휴대폰 사진도 편집할 수 있나요?

네. 휴대폰에서 사진을 선택하고 손가락으로 드래그해 적용한 뒤 PNG로 저장할 수 있습니다.
