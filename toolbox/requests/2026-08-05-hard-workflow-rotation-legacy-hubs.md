# 하드 워크플로: 기존 통합 도구 순환 개선

## 확정 범위

- 대상: 인코딩·문자 변환, 다용도 계산, CSS 디자인, 텍스트 정리·생성, 마크다운 작성, 개발자 빠른 참조·검사 도구 6개
- 신규·통합 기능 3건: Base64·Data URL 메타정보 확인, 주말 제외 날짜 차이, 접근성 색상 CSS 변수 묶음
- 개별 개선 6건: Base64 결과 용량·MIME 안내, 날짜 계산의 달력일·평일 구분, 색상 결과의 즉시 사용 CSS, 텍스트 문단·읽기 시간 집계, 마크다운 문서 구조 통계와 빈 저장 보호, HTTP 상태별 후속 행동 안내
- 공통 수정 2건: 초기화 뒤 모바일 자동 포커스 제거, 복사 대체 결과 표시 뒤 모바일 자동 포커스·강제 선택 제거

## 실행 원칙

- 최근 두 하드 회차에서 다루지 않은 공개 도구를 우선 순환한다.
- 별도 저가치 페이지를 늘리지 않고 기존 사용 맥락에 실사용 기능을 통합한다.
- 이전 버전과 은퇴 도구의 호환 진입점은 변경하지 않는다.
- 각 변경은 한국어·영어 상태, 375px 세로 화면, iframe 높이와 빈 결과 오류 복구를 함께 검증한다.
- Blogger 반영, 독립 커밋·푸시와 공개 배포가 확인된 뒤에만 완료로 기록한다.

## Skill·Markdown 효율 개선

- 미확인 기록 보고 시 각 JSON의 `reportHistory`를 수동으로 편집하지 않도록 관리 스크립트에 보고 전용 명령을 추가한다.
- 보고할 기록의 기능 내용이나 워크플로 선택을 고정하지 않고, 기존 미확인 폴더만 대상으로 요약과 보고 이력 기록을 한 번에 처리한다.
