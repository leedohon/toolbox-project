## 기능
- Ctrl/⌘+Enter PNG 저장과 화면 단축키 안내
- 작은 개인정보 영역을 가리기 위한 정밀 브러시 설정


- PNG, JPEG, WebP 파일 선택 및 드래그 앤 드롭
- 파일 없이 바로 익히는 샘플 이미지 체험
- 마우스와 터치로 브러시 칠하기 또는 사각형 범위 선택
- 사각형 드래그 중 선택 범위 미리보기, 종료 시 범위 전체 적용
- 브러시 크기와 모자이크 강도 조절
- 버튼 또는 `Ctrl/Cmd + Z`로 한 단계 되돌리기, 원본 초기화, PNG 저장
- 현재 편집 단계 수와 이미지 로드 전 비활성 동작 표시
- 되돌린 모자이크 한 단계를 버튼 또는 `Ctrl/Cmd + Shift + Z`로 다시 실행
- 넓은 브러시와 강한 모자이크 값을 한 번에 적용하는 빠른 설정
- 편집 단계를 잃지 않고 원본과 현재 편집본을 전환해 비교
- 저장할 PNG 파일명을 직접 지정하고 사용할 수 없는 문자를 자동 정리

## 규칙

- 파일은 15MB 이하로 제한한다.
- 이미지 한 변은 5,000px 이하, 전체 픽셀은 20,000,000 이하로 제한한다.
- 이미지는 서버로 전송하지 않고 브라우저에서만 처리한다.
- 브러시와 사각형 적용을 합해 최대 100개의 되돌리기 단계를 보관한다.

## 공통 언어

- 공통 `KOR / ENG` 선택기를 사용하며 파일 안내·오류·편집 상태까지 선택 언어로 표시한다.

## 키보드 접근성

- 파일 드롭 영역은 Enter 또는 Space 키로 파일 선택 창을 열 수 있어야 한다.

## 이번 개선

- `원본 비교` 버튼으로 편집본을 보존한 채 가림 전후를 확인한다.
- 파일·편집·저장 안내를 KOR / ENG 선택에 맞춘다.
