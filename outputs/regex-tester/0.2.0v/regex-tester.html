정규식으로 텍스트 검사하기

도구가 보이지 않으면 새 창에서 열기를 이용하세요.

사용 방법

  1. 정규식 패턴과 필요한 플래그를 입력합니다.
  2. 검사할 텍스트를 입력합니다.
  3. 일치 항목과 강조된 결과를 확인하고 필요하면 복사합니다.

정규식 테스트 도구 상세 설명

정규식 테스트 도구는 패턴을 작성하면서 문장 안에서 어떤 부분이 일치하는지 즉시 확인할 때 사용합니다. 일치 목록에서 번호·이름 있는 캡처 그룹 값을 확인하고, 치환식을 켜면 캡처 그룹을 반영한 변경 결과까지 같은 화면에서 미리 봅니다.

입력과 검사는 현재 브라우저 안에서만 처리됩니다. 매우 복잡한 패턴은 브라우저를 느리게 할 수 있으므로 패턴과 텍스트 길이를 제한하며, 일치 결과도 안전한 개수까지만 표시합니다.

실제 적용 환경이 JavaScript가 아니라면 같은 패턴을 대상 언어에서도 다시 시험하세요. 짧은 예제에서 맞는 패턴도 긴 입력에서 느려질 수 있으므로 반복 범위를 구체화하고 예상 일치·불일치 사례를 함께 테스트하는 편이 안전합니다.

활용 예시

문장에서 휴대전화 형식 찾기

입력
패턴 \b010-\d{4}-\d{4}\b와 문장 문의 010-1234-5678, 예비 02-123-4567을 입력합니다.
결과
010-1234-5678 한 항목만 일치하며 일치 문자열과 시작 위치가 목록과 하이라이트에 표시됩니다.

로그의 ERROR 표기를 대소문자 없이 찾기

입력
패턴 error, 플래그 g·i, 테스트 문장 ERROR 500\nerror 404를 입력합니다.
결과
대소문자가 다른 두 error가 모두 일치 항목으로 잡혀 각 위치와 함께 표시됩니다.

결과 확인 전 알아두기

  • 브라우저 JavaScript 정규식 문법을 사용하므로 PCRE, Python이나 Java 전용 기능과 결과가 다를 수 있습니다.
  • 패턴은 최대 500자, 테스트 문장은 최대 50,000자이며 일치 목록은 최대 200개까지 표시합니다.
  • 일치 여부와 위치를 검사하는 도구로 문자열 치환, 정규식 성능 보증과 치명적 백트래킹 분석은 제공하지 않습니다.

자주 묻는 질문

정규식 플래그는 무엇인가요?

g는 전체 일치, i는 대소문자 무시, m은 여러 줄 기준, s는 줄바꿈까지 점으로 포함하는 옵션입니다. g를 끄면 첫 일치만 찾고 치환합니다.

패턴 양쪽에 슬래시를 입력해야 하나요?

아니요. 슬래시 없이 패턴 내용만 입력하세요.

일치 항목이 너무 많으면 어떻게 되나요?

화면이 느려지지 않도록 최대 200개까지만 표시하고 나머지는 안내합니다.

입력한 텍스트가 서버로 전송되나요?

아니요. 모든 검사는 현재 브라우저에서만 실행됩니다.
