# 2026-07-24 추가 후보 통합·선정 크리에이트

## 사용자 요청

- 기존 공개 도구와 겹치지 않는 추가 후보를 먼저 목적별로 합친다.
- 단독 기능 20개를 그대로 공개하지 않고, 실제 사용성이 높은 묶음 몇 개만 선정해 구현·게시한다.
- 자동 워크플로, Blogger 게시, Git `main` 반영과 GitHub Pages 공개 확인까지 한 번에 처리한다.
- 종료 예약은 사용하지 않는다.
- 개발 토큰 효율은 실제 입·출력 토큰과 같은 규모의 기준 실행을 제공하지 않는 환경이므로 `proxy_only`로 기록한다.

## 기존 도구 중복 점검

- 인코딩·진법·유니코드·HTML 엔티티는 `base64-tools`와 겹치므로 제외한다.
- 일반 단위·날짜·백분율·기초 통계는 `date-calculator`와 겹치므로 제외한다.
- CSS 색상·대비·그라데이션·그림자·단위·모서리는 `color-converter-contrast`와 겹치므로 제외한다.
- 글자수·공백·파일명·슬러그·줄 정리·임시 문장은 `text-counter-cleaner`와 겹치므로 제외한다.
- JSON·CSV·XML·마크다운·URL 분석·정규식·JWT·해시·이미지 변환과 기존 뽑기 기능은 새 후보에서 제외한다.
- 분수 약분처럼 단독 가치가 낮은 한 기능 페이지를 다시 만들지 않는다.

## 구현 경계

- 모든 계산·추출·코드 생성은 현재 브라우저 안에서만 처리한다.
- 텍스트 추출은 정규식 원문을 요구하지 않고, 선택한 유형의 결과를 중복 제거·정렬해 제공한다. 전화번호는 국가별 모든 형식을 보장하지 않으며 오탐 가능성을 안내한다.
- 웹 메타 도구는 외부 주소를 가져오거나 검색 노출을 보장하지 않고, 사용자가 입력한 값의 미리보기와 태그 코드만 생성한다.
- 금융 계산은 세금·수수료·중도상환·상품 추천을 제외한 참고용 수학 계산으로 제한한다.
- IP 도구는 IPv4와 MAC 주소 형식만 다루고 실제 네트워크 접속·조회·스캔을 하지 않는다.
- 좌표 거리는 지구 구면을 이용한 근사 대권거리이며 도로 이동 거리나 측량 결과로 안내하지 않는다.
- 모든 화면은 KOR / ENG, 복사 대체 처리, 안전 포커스, iframe 높이 동기화와 세로 한 열 입력을 지원한다.
- 조건부 필드는 `showWhen`을 사용해 선택한 모드에서만 표시한다.

## 릴리스·게시

- 다섯 도구 모두 `published`, 최초 `0.0.1v`, 변경 등급 `minimum`으로 생성한다.
- 도구 정의, embed, 게시글, 버전 HTML, 패치노트, 카탈로그, 다국어와 AI 색인을 함께 만든다.
- 각 게시글은 상세 설명 두 문단 이상, 사용자 FAQ 네 개 이상, 검색 키워드 20~30개와 누적 패치노트를 포함한다.
- 로컬 반응형·회귀 검사를 완료한 뒤 실제 검사 결과를 `patch-notes.json`의 `qa`에 기록한다.
- 전체 완성 후 Blogger에 다섯 게시글을 공개하고 URL을 동기화한다.
- 관련 변경을 한 커밋으로 `main`에 푸시한 뒤 GitHub Pages의 다섯 고정 embed 주소를 확인한다.
- 종료 예약과 시스템 종료 작업은 만들지 않는다.

## 토큰 효율 측정

- 측정 상태: `proxy_only`
- 전체 개발 토큰 감소율: 계산하지 않음
- 확인 가능한 대체 지표: 후보 공개 진입점 `20 → 5`, 감소율 `75%`
- 실제 입·출력 토큰 수와 같은 종류·규모의 기준 실행이 없으므로 75%를 전체 개발 토큰 감소율로 보고하지 않는다.
