CSV 표 보기·변환기

CSV·TSV 텍스트를 표로 확인하고 JSON 또는 다른 구분자 형식으로 변환합니다.

  • 쉼표·탭·세미콜론 자동 판별
  • 따옴표와 줄바꿈 포함 셀 처리
  • 최대 100행 표 미리보기
  • JSON·CSV·TSV 복사와 저장

CSV 데이터를 표로 확인하고 변환하기

도구가 보이지 않으면 새 창에서 열기를 이용하세요.

사용 방법

  1. CSV 또는 TSV 텍스트를 입력하거나 파일을 선택합니다.
  2. 자동 판별된 구분자와 첫 행 제목 사용 여부를 확인합니다.
  3. 표 미리보기를 확인한 뒤 JSON, CSV 또는 TSV로 복사·저장합니다.

CSV 표 보기·변환기 상세 설명

CSV 표 보기·변환기는 스프레드시트나 업무 시스템에서 받은 쉼표·탭 구분 데이터를 브라우저에서 바로 확인할 때 사용합니다. 따옴표 안의 쉼표와 줄바꿈을 구분해 읽고 JSON, CSV, TSV뿐 아니라 문서에 붙일 Markdown 표로도 변환합니다.

파일과 텍스트는 서버에 업로드하지 않고 현재 브라우저에서만 처리합니다. 완전히 빈 행을 무시하거나 모든 셀의 앞뒤 공백을 정리할 수 있고, 행과 열을 한 번에 바꾸는 전치 기능도 제공합니다. 열 개수가 맞지 않는 행은 가까운 오류 안내로 알려 줍니다.

변환 전 첫 행이 열 이름인지, 구분자와 문자 인코딩이 무엇인지 확인하세요. 쉼표가 포함된 값은 따옴표 규칙이 지켜져야 하며, 날짜·긴 숫자·앞자리 0은 스프레드시트에서 자동 형식 변환될 수 있어 저장 후 재확인이 필요합니다.

활용 예시

쉼표가 포함된 셀을 JSON으로 변환

입력
name,note\n지수,"서울, 강남"을 입력하고 첫 행을 열 이름으로 사용해 JSON 변환을 선택합니다.
결과
[{"name":"지수","note":"서울, 강남"}] 구조의 JSON이 생성되어 셀 안의 쉼표가 한 값으로 유지됩니다.

탭 구분 목록을 CSV로 바꾸기

입력
상품\t수량\n노트\t3을 입력하고 구분자 자동 판별, 출력 형식 CSV를 선택합니다.
결과
상품,수량\n노트,3 형식의 쉼표 구분 결과를 복사하거나 CSV 파일로 저장할 수 있습니다.

결과 확인 전 알아두기

  • 파일 입력은 5MB 이하, 직접 입력은 최대 1,000,000자까지 처리합니다.
  • 화면 표는 최대 100행만 보여 주지만 변환 결과에는 유효하게 읽은 전체 행이 포함됩니다.
  • JSON 변환 시 숫자와 날짜도 원본 셀 문자열로 저장되며 열 개수가 다른 행이나 닫히지 않은 따옴표는 오류로 처리됩니다.

자주 묻는 질문

어떤 구분자를 지원하나요?

쉼표, 탭, 세미콜론과 세로 막대를 지원하며 자동 판별하거나 직접 선택할 수 있습니다.

따옴표 안의 쉼표도 처리되나요?

네. 큰따옴표로 감싼 셀 안의 쉼표와 줄바꿈은 하나의 값으로 처리합니다.

CSV 파일이 서버로 올라가나요?

아니요. 파일 읽기, 표 생성과 변환은 현재 브라우저 안에서만 진행됩니다.

행마다 열 개수가 다르면 어떻게 되나요?

첫 행의 열 개수와 다른 행 번호를 표시하므로 원본 데이터를 바로 고칠 수 있습니다.

CSV 사이의 빈 줄도 결과에 포함되나요?

기본값은 완전히 빈 행을 무시합니다. 빈 행을 유지하려면 해당 선택을 끄면 됩니다.
