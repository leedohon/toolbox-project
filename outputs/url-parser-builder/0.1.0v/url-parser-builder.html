URL 분석·쿼리 편집기

URL의 주소 구성요소와 쿼리 항목을 나누어 확인하고 수정한 주소를 다시 만듭니다.

  • 프로토콜·호스트·경로 분석
  • 쿼리 항목별 편집
  • 중복 쿼리 키 보존
  • 완성 URL 복사

URL 분석하고 다시 만들기

도구가 보이지 않으면 새 창에서 열기를 이용하세요.

사용 방법

  1. http 또는 https URL을 입력합니다.
  2. 분석된 구성요소와 번호가 있는 쿼리 행을 확인합니다.
  3. 값을 수정하거나 행을 추가한 뒤 완성 URL을 복사합니다.

URL 분석·쿼리 편집기 상세 설명

URL 분석·쿼리 편집기는 긴 주소를 프로토콜, 호스트, 포트, 경로, 해시와 쿼리 항목으로 나누어 보여 줍니다. 각 쿼리 행에 번호·이름·값 라벨을 고정해 좁은 세로 화면에서도 어떤 칸을 편집하는지 바로 구분할 수 있습니다.

쿼리 이름과 값은 URLSearchParams 규칙으로 안전하게 인코딩해 다시 조립합니다. 필요하면 UTM source·medium·campaign 기본 항목을 한 번에 추가할 수 있으며, 모든 분석과 편집은 현재 브라우저에서만 실행합니다.

편집한 주소는 복사 후 새 탭에서 열어 경로와 쿼리가 의도한 결과를 만드는지 확인하세요. 중복 키 순서와 빈 값의 의미는 서버마다 다를 수 있으므로 분석 결과가 문법적으로 정상이어도 대상 서비스 동작은 별도로 검증해야 합니다.

활용 예시

중복 쿼리 항목을 행별로 확인

입력
https://example.com/tools?lang=ko&tag=web&tag=utility#guide를 입력합니다.
결과
프로토콜 https:, 호스트 example.com, 경로 /tools, 해시 #guide가 분리되고 tag=web과 tag=utility가 서로 다른 두 행으로 유지됩니다.

검색 주소에 캠페인 값을 추가

입력
https://example.com/search?q=toolbox를 분석한 뒤 utm_source=blogger 행을 추가합니다.
결과
https://example.com/search?q=toolbox&utm_source=blogger 형태의 완성 URL이 즉시 갱신되어 복사할 수 있습니다.

결과 확인 전 알아두기

  • http 또는 https로 시작하는 전체 주소만 처리하며 사용자 이름이나 비밀번호가 포함된 URL은 거부합니다.
  • 주소 문자열을 브라우저에서 분석할 뿐 해당 서버에 접속하거나 페이지 존재 여부, 리디렉션과 응답 상태를 확인하지 않습니다.
  • 쿼리 이름과 값은 URL 규칙에 맞게 다시 인코딩되므로 사람이 입력한 원래의 퍼센트 인코딩 표기와 모양이 달라질 수 있습니다.

자주 묻는 질문

상대 주소도 분석할 수 있나요?

현재는 오해를 줄이기 위해 http 또는 https로 시작하는 전체 URL만 지원합니다.

같은 쿼리 이름이 여러 번 있어도 되나요?

네. 각 항목을 별도 행으로 유지해 순서와 중복 키를 보존합니다.

한글 쿼리 값은 어떻게 처리되나요?

편집 결과를 만들 때 브라우저 표준 방식으로 안전하게 퍼센트 인코딩합니다.

UTM 기본 항목을 빠르게 추가할 수 있나요?

네. UTM 기본 3종 추가를 누르면 현재 목록에 없는 utm_source, utm_medium, utm_campaign 행만 추가합니다.

입력한 URL이 서버로 전송되나요?

아니요. 주소 분석과 재구성은 현재 브라우저 안에서만 처리합니다.
