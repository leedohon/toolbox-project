웹페이지 제목과 설명, 주소와 이미지를 입력해 검색·공유 미리보기와 메타 태그를 함께 만듭니다.

  • 검색 제목·설명 미리보기
  • Open Graph 태그 생성
  • Twitter/X 카드 태그 생성
  • canonical·robots 메타 생성

메타 미리보기와 태그 만들기

도구가 보이지 않으면 새 창에서 열기를 이용하세요.

사용 방법

  1. 페이지 제목과 설명, 대표 주소와 공유 이미지 주소를 입력합니다.
  2. 검색 로봇 설정을 선택하고 미리보기를 만듭니다.
  3. 검색·공유 카드와 생성된 메타 태그를 확인해 복사합니다.

웹 메타·공유 미리보기 상세 설명

웹 메타·공유 미리보기는 한 번의 입력으로 검색 결과에 보일 제목·설명과 링크 공유 카드의 기본 모습을 확인합니다. 같은 값으로 Open Graph와 Twitter/X 카드 태그, canonical과 robots 메타를 만들어 반복 입력을 줄입니다.

제목과 설명 길이는 일반적인 권장 범위와 비교해 안내하고, 공유 이미지가 있으면 대체 설명을 og:image:alt·twitter:image:alt와 JSON-LD 이미지 설명에 반영합니다. 외부 주소를 가져오지 않으며 HTML 특수문자를 안전하게 처리합니다.

생성 코드를 적용한 뒤에는 실제 공개 URL의 원본 소스와 검색·공유 디버거에서 다시 확인하세요. 캐시, 접근 제한, 이미지 크기와 플랫폼별 잘림 때문에 로컬 미리보기와 실제 검색·공유 카드가 다르게 나타날 수 있습니다.

활용 예시

게시글의 검색·공유 태그 한 번에 만들기

입력
페이지 제목, 한 문단 설명, https://example.com/guide와 대표 이미지 절대 주소를 입력합니다.
결과
title·description·canonical·robots와 Open Graph·Twitter/X 태그가 한 HTML 조각으로 생성됩니다.

비공개 안내 페이지의 robots 값 점검

입력
robots에서 noindex,follow를 선택하고 페이지 정보를 입력합니다.
결과
미리보기와 함께 <meta name="robots" content="noindex,follow">가 포함된 기본 메타 태그가 표시됩니다.

결과 확인 전 알아두기

  • 검색 엔진과 소셜 서비스는 제목·설명·이미지를 다시 선택하거나 표시 길이를 바꿀 수 있어 미리보기와 실제 노출이 같다고 보장하지 않습니다.
  • 입력한 URL의 존재 여부, 응답 상태, 이미지 크기와 크롤러 접근 가능 여부는 네트워크로 검사하지 않습니다.
  • 생성된 코드는 HTML head에 적용할 작성 보조 결과이며 robots 설정의 효과는 실제 배포와 검색 엔진 재수집 뒤에 결정됩니다.

자주 묻는 질문

실제 검색 결과와 똑같이 보이나요?

아니요. 서비스가 제목과 설명을 다시 선택하거나 화면을 바꿀 수 있으므로 작성 전 길이와 내용을 점검하는 참고용입니다.

Open Graph와 Twitter/X 태그를 따로 입력해야 하나요?

아니요. 같은 제목·설명·주소·이미지를 사용해 두 묶음을 함께 생성합니다.

이미지 주소가 꼭 필요한가요?

필수는 아니지만 링크 공유 카드에 이미지를 표시하려면 공개적으로 접근 가능한 절대 주소를 사용하고, 이미지가 있을 때는 핵심 내용을 설명하는 대체 문구도 입력하세요.

웹사이트 주소를 직접 검사하나요?

아니요. 외부 페이지를 불러오지 않고 사용자가 입력한 값으로 미리보기와 코드를 만듭니다.

noindex를 선택하면 바로 검색에서 사라지나요?

아니요. 생성한 태그를 실제 페이지에 적용해야 하며 검색 엔진의 재수집 시점에 따라 반영 시간이 달라집니다.
