사용 방법

  1. CIDR, 마스크, IP 범위 또는 MAC 주소 작업을 선택합니다.
  2. 선택한 모드에 표시되는 주소나 프리픽스를 입력합니다.
  3. 계산된 네트워크 범위와 표준 주소 형식을 확인합니다.

IP·네트워크 주소 도구 상세 설명

IP·네트워크 주소 도구는 IPv4 주소와 CIDR 프리픽스를 이용해 네트워크 주소, 브로드캐스트 주소, 전체·사용 가능 주소 범위를 계산합니다. 지정한 IPv4가 CIDR 범위 안에 포함되는지도 네트워크 범위와 함께 바로 확인할 수 있습니다.

연속된 시작·끝 IPv4 범위는 최소 CIDR 목록으로 나누고 MAC 주소는 표준 형식으로 정리합니다. CIDR 계산 시 입력 주소가 사설·공인 후보·루프백·문서 예시 등 어느 용도인지 함께 판별하며 실제 네트워크에는 접속하지 않습니다.

계산 결과를 장비 설정에 적용하기 전에는 예약 주소, 게이트웨이, DHCP 범위와 조직의 서브넷 정책을 함께 확인하세요. 수학적으로 유효한 CIDR도 기존 네트워크와 겹치거나 장비별 /31·/32 처리 규칙과 충돌할 수 있습니다.

활용 예시

사설망 주소의 /24 범위 확인

입력
CIDR 계산에 192.168.1.42/24를 입력합니다.
결과
네트워크 192.168.1.0/24, 브로드캐스트 192.168.1.255, 일반 사용 가능 범위 192.168.1.1–192.168.1.254가 표시됩니다.

연속 IP 범위를 최소 CIDR로 나누기

입력
시작 10.0.0.0과 끝 10.0.0.255를 범위 변환에 입력합니다.
결과
범위를 벗어나지 않는 최소 목록인 10.0.0.0/24 한 개로 정리됩니다.

결과 확인 전 알아두기

  • IPv4와 48비트 MAC 문자열만 지원하며 IPv6, VLAN, 라우팅 경로와 실제 장비 상태는 처리하지 않습니다.
  • /31과 /32는 일반적인 네트워크·브로드캐스트 제외 규칙과 다른 특수 용도가 있으므로 표시된 전체 범위를 환경 규칙과 함께 확인해야 합니다.
  • MAC 주소는 구분자와 형식만 정리하며 제조사, 위치, 기기 소유자나 네트워크 연결 상태를 조회하지 않습니다.

자주 묻는 질문

IPv6도 지원하나요?

최초 버전은 IPv4 CIDR과 48비트 MAC 주소에 집중합니다.

/31과 /32의 사용 가능 주소는 어떻게 표시하나요?

주소 개수와 범위를 그대로 표시하고, 일반적인 네트워크·브로드캐스트 제외 규칙과 다른 특수 범위임을 함께 안내합니다.

IP 범위를 CIDR로 바꾸면 범위 밖 주소가 포함되나요?

아니요. 시작과 끝 주소 사이만 정확히 덮는 최소 CIDR 목록을 만듭니다. 별도의 포함 여부 모드에서는 특정 IPv4가 지정한 CIDR 범위 안에 있는지도 확인할 수 있습니다.

MAC 주소로 제조사를 찾을 수 있나요?

아니요. 주소 형식 검사와 표준화만 제공하며 제조사 데이터베이스를 조회하지 않습니다.

실제 네트워크를 검사하나요?

아니요. 입력한 주소만 브라우저에서 계산하며 접속이나 스캔을 수행하지 않습니다.

공인 IPv4 후보라는 결과는 실제 사용 가능하다는 뜻인가요?

아니요. 대표 사설·특수 대역에 속하지 않는다는 간단한 분류이며 실제 할당과 접근 가능 여부는 별도로 확인해야 합니다.
