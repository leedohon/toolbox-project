# 하드 워크플로 3회차 — 형식·미디어 도구

- 실행 ID: `20260809-142207-hard`
- 예약 종료: 없음
- 대상: QR·바코드, JSON, 다용도 뽑기게임, 비밀번호, 이미지 크기·압축, CSV 변환기

## 확정 범위

- QR·바코드의 전경색과 배경색을 한 번에 교환한다.
- JSON 객체 키를 재귀적으로 정렬한 결과를 기존 정리 흐름 안에서 제공한다.
- 다용도 뽑기게임은 현재 게임을 URL에 반영해 다시 열 수 있게 한다.
- 비밀번호 생성기에 웹사이트용 안전 설정 프리셋을 제공한다.
- 이미지 크기 도구에 긴 변 1280px·1920px 프리셋을 통합한다.
- CSV 셀 앞뒤 공백 정리 선택을 제공한다.
- 수정된 결과를 모바일·데스크톱과 Blogger 공개 화면에서 검증하고 독립 배포한다.

## 효율 개선

- Blogger 갱신 대상은 실행 결과의 `selectedTools`에서 읽는 `--from-run` 옵션으로 전달한다.
- 실제 토큰 계측값이 없으므로 전체 개발 토큰 감소율은 확정하지 않고 대체 지표만 기록한다.
