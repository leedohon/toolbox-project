사용 방법

  1. 검사할 XML을 입력하거나 붙여넣습니다.
  2. 들여쓰기 또는 압축 방식을 선택합니다.
  3. 오류 위치를 고치거나 정리 결과를 복사·저장합니다.

XML 검사·정리 도구 상세 설명

XML 검사·정리 도구는 브라우저의 표준 XML 파서를 사용해 태그 닫힘, 속성 따옴표, 문서 구조 오류를 확인합니다. 유효한 문서는 선택한 들여쓰기 폭으로 읽기 좋게 정리하거나 공백을 줄인 한 줄 결과로 바꿉니다.

입력과 변환 결과는 현재 브라우저에서만 처리합니다. 외부 엔티티를 가져오거나 스키마 유효성을 판정하지 않으며, 일반적인 XML 문법과 구조를 빠르게 점검하는 용도에 집중합니다.

활용 예시

상품 XML을 2칸 들여쓰기로 정리

입력
<catalog><item id="1"><name>노트</name><price>3000</price></item></catalog>를 입력하고 2칸 정리를 선택합니다.
결과
catalog, item, name, price의 포함 관계가 줄바꿈과 2칸 들여쓰기로 정리된 XML이 생성됩니다.

닫히지 않은 태그 찾기

입력
<catalog><item>노트</catalog>를 입력합니다.
결과
item 태그가 올바르게 닫히지 않은 문법 오류를 감지하고 변환 결과 대신 오류 안내를 표시합니다.

결과 확인 전 알아두기

  • XML 문법과 태그 구조만 검사하며 XSD·DTD 스키마 규칙이나 업무 데이터의 유효성은 검증하지 않습니다.
  • 직접 입력은 최대 1,000,000자까지 처리하므로 그보다 큰 XML은 전용 스트리밍 도구가 필요합니다.
  • 한 줄 압축은 요소 사이 공백을 줄일 수 있으므로 텍스트 공백이 의미를 갖는 문서는 결과를 확인한 뒤 사용해야 합니다.

자주 묻는 질문

XML 스키마나 DTD도 검증하나요?

아니요. 기본 XML 문법과 문서 구조를 검사하며 외부 스키마 검증은 수행하지 않습니다.

민감한 XML이 서버로 전송되나요?

아니요. 입력과 정리 결과는 현재 브라우저 안에서만 처리합니다.

들여쓰기는 몇 칸을 지원하나요?

읽기 좋은 2칸과 4칸 들여쓰기를 선택할 수 있습니다.

주석과 CDATA는 유지되나요?

네. 표준 파서가 읽은 주석과 CDATA 구간을 결과에 보존합니다.
