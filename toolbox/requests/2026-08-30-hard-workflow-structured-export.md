# 하드 워크플로 구조화 결과 내보내기

- 실행 ID: `20260830-193118-hard`
- 대상: HTTP 상태, 텍스트 추출, 웹 메타, 대출·저축, IP 네트워크, 좌표·거리 도구
- 각 도구의 현재 결과를 도구·모드·항목 순서를 보존한 JSON으로 복사하고 파일로 저장한다.
- 공통 `Alt+J` 복사와 `Alt+D` 저장 계약을 한 모듈에서 제공한다.
- 모바일과 데스크톱에서 결과 생성 전 안내, 클립보드 대체 표시, 저장 파일명과 가로 넘침을 확인한다.
- 삭제, 휴지통 이동, 공개 글의 초안 전환 및 시스템 종료는 수행하지 않는다.
