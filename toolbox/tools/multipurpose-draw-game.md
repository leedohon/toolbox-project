## 기능
- 결과를 만든 뒤 Blogger 게시글 주소로 된 `결과 링크 복사`를 제공하고, 링크를 연 사람에게 같은 게임 모드와 확정 결과를 자동 복원
- 공유 링크가 메신저 길이 한도를 넘으면 기존 결과 코드 또는 PNG 저장을 안내
- 선택한 게임 모듈만 새 탭에서 단독으로 열기
- 선택한 게임 모드가 포함된 현재 링크 복사와 수동 복사 대체 표시
- 현재 입력 상태를 유지하면서 이전 게임으로 순환하는 빠른 이동


- 사다리, 돌림판, 숫자뽑기, 편가르기 네 모드
- 4개 이하 선택지에 맞춘 라디오 카드형 모드 선택
- 모드 전환 뒤에도 각 모듈의 입력과 결과 상태 유지
- 처음에는 선택한 게임만 불러오고 다른 게임은 처음 열 때 준비해 초기 로딩을 줄임
- 브라우저가 선택 기억을 차단해도 게임 전환과 실행은 계속 지원
- 각 모드의 KOR / ENG, 결과 코드 복원, PNG 저장과 복사 대체 처리 유지
- 브라우저 안에서만 입력과 무작위 결과 처리
- 모드 라디오 카드에서 방향키·Home·End로 게임 이동
- 선택한 게임을 URL에 반영해 같은 주소로 다시 열면 해당 게임을 바로 표시
- 현재 입력 상태를 유지하면서 다음 게임으로 순환하는 빠른 이동

## 모듈 구조

- 공개 진입점: `embed/multipurpose-draw-game/index.html`

- 기존 네 놀이 엔진을 호환 모듈로 재사용해 이미 공유된 결과 코드를 보존한다.

## 명칭

- 카테고리: `다용도 펀박스`
- 도구명: `다용도 뽑기게임`
- 팀 배정 모드의 공개 명칭은 `편가르기`이며 `다중팀`을 사용하지 않는다.

## 공통 언어

- 컨테이너 상단에도 공통 `KOR / ENG` 선택기를 제공하고 선택을 현재 게임 모듈에 전달한다.

## 이번 개선
