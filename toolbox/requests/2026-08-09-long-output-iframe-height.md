# 장문 결과와 iframe 높이 안정화

## 보고된 문제

- 텍스트를 많이 입력하면 실행 화면의 실제 내용은 길어지지만 바깥 레이아웃 높이가 일정 지점에서 더 이상 따라오지 않는다.
- 텍스트 비교처럼 결과 행을 입력 길이만큼 만드는 기능에서 잘림, 내부 스크롤 또는 멈춘 높이가 발생할 수 있다.

## 확정 범위

- 영향도가 큰 텍스트 비교, 마크다운 미리보기·HTML 결과, CSV 표 미리보기를 우선 수정한다.
- 이미 긴 결과 영역을 제한하는 정규식 테스트 도구는 같은 대량 입력 회귀검사로 보호한다.
- 장문 결과는 페이지 전체를 무한히 늘리지 않고, 제목과 상태를 유지한 채 읽기 가능한 최대 높이 안에서 세로 스크롤한다.
- 도구 허브와 Blogger 수신기는 최대 높이를 넘는 메시지를 버리지 않고 안전한 상한으로 반영하며, 내용이 다시 짧아지면 높이도 줄인다.

## 완료 조건

- 대량 입력 뒤 상위 iframe 높이가 마지막 정상값에서 멈추지 않는다.
- 텍스트 비교·마크다운·CSV의 긴 결과를 각 결과 영역 안에서 끝까지 볼 수 있다.
- 모바일 375px와 데스크톱 1280px에서 가로 넘침과 페이지 단위 이중 세로 스크롤이 없다.
- 입력을 짧게 되돌리거나 결과를 초기화하면 iframe 높이가 다시 감소한다.
