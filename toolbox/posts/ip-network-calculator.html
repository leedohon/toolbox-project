IP·네트워크 주소 도구 상세 설명

IP·네트워크 주소 도구는 IPv4 주소와 CIDR 프리픽스를 이용해 네트워크 주소, 브로드캐스트 주소, 전체·사용 가능 주소 범위를 계산합니다. 프리픽스만 입력하면 서브넷 마스크와 와일드카드 마스크를 함께 확인할 수 있습니다.

연속된 시작·끝 IPv4 범위는 범위를 정확히 덮는 최소 CIDR 목록으로 나누며, MAC 주소는 콜론·하이픈·점 표기를 읽어 표준 형식으로 정리합니다. 실제 장비나 외부 네트워크에 접속하지 않고 입력 문자열만 현재 브라우저에서 처리합니다.

자주 묻는 질문

IPv6도 지원하나요?

최초 버전은 IPv4 CIDR과 48비트 MAC 주소에 집중합니다.

/31과 /32의 사용 가능 주소는 어떻게 표시하나요?

주소 개수와 범위를 그대로 표시하고, 일반적인 네트워크·브로드캐스트 제외 규칙과 다른 특수 범위임을 함께 안내합니다.

IP 범위를 CIDR로 바꾸면 범위 밖 주소가 포함되나요?

아니요. 시작과 끝 주소 사이만 정확히 덮는 최소 CIDR 목록을 만듭니다.

MAC 주소로 제조사를 찾을 수 있나요?

아니요. 주소 형식 검사와 표준화만 제공하며 제조사 데이터베이스를 조회하지 않습니다.

실제 네트워크를 검사하나요?

아니요. 입력한 주소만 브라우저에서 계산하며 접속이나 스캔을 수행하지 않습니다.
