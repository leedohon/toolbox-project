텍스트·파일 해시 생성기

텍스트나 파일을 선택해 SHA-256·SHA-384·SHA-512 해시값을 브라우저에서 계산합니다.

  • 텍스트와 파일 입력
  • SHA-256·SHA-384·SHA-512
  • 대문자·소문자 출력
  • 결과 복사

해시값 계산하기

도구가 보이지 않으면 새 창에서 열기를 이용하세요.

사용 방법

  1. 텍스트를 입력하거나 파일을 선택합니다.
  2. 해시 알고리즘과 출력 형식을 선택합니다.
  3. 계산한 해시값을 복사합니다.

텍스트·파일 해시 생성기 상세 설명

해시는 같은 입력에서 항상 같은 길이의 식별값을 만드는 방식입니다. 다운로드 파일의 무결성을 대조하거나 두 텍스트가 같은지 확인할 때 원문 전체를 비교하지 않고도 사용할 수 있습니다.

입력한 텍스트와 파일은 서버로 전송하지 않고 현재 브라우저의 Web Crypto 기능으로 처리합니다. SHA-256·SHA-384·SHA-512를 하나씩 또는 한 번에 계산할 수 있고, 텍스트 앞뒤 공백을 명시적으로 제거한 뒤 계산하거나 제공받은 기대 해시와 일치 여부도 확인할 수 있습니다.

해시를 대조할 때는 양쪽에서 같은 알고리즘과 같은 파일 바이트를 사용했는지 확인하세요. 표시 대소문자는 비교 전에 통일할 수 있지만 파일의 줄바꿈·인코딩·압축 상태가 달라지면 내용이 비슷해도 결과는 완전히 달라집니다.

해시를 대문자 형식으로 출력

입력

결과
BA7816BF8F01CFEA414140DE5DAE2223B00361A396177A9CB410FF61F20015AD가 생성되어 대문자 체크섬 목록과 바로 대조할 수 있습니다.

결과 확인 전 알아두기

  • 파일 입력은 20MB 이하만 처리하며 더 큰 파일의 스트리밍 해시는 지원하지 않습니다.
  • 해시가 같다는 사실은 내용이 같을 가능성을 확인할 뿐 배포자 신원이나 파일의 안전성을 인증하지 않습니다.
  • SHA-256·SHA-384·SHA-512 체크섬만 제공하며 비밀번호 저장용 솔트, 반복 해싱이나 키 기반 인증 기능은 없습니다.

자주 묻는 질문

파일이 서버로 전송되나요?

아니요. 선택한 파일은 현재 브라우저에서만 읽어 해시를 계산합니다.

어떤 알고리즘을 선택하면 되나요?

일반적인 무결성 확인에는 SHA-256이 널리 쓰이며, 상대방이 지정한 알고리즘이 있으면 같은 항목을 선택하세요. 여러 형식을 함께 전달해야 하면 3개 모두를 선택할 수 있습니다.

같은 파일인데 해시가 다를 수 있나요?

파일 내용이 한 바이트라도 달라지면 해시가 달라집니다. 기대 해시 칸에 원래 값을 붙여 넣으면 대소문자와 공백을 제외하고 일치 여부를 바로 확인할 수 있습니다.

해시로 원문을 복원할 수 있나요?

아니요. 이 도구의 해시는 원문으로 되돌리는 인코딩이 아닙니다.
