# 하드 워크플로 2회차: 콘텐츠·네트워크·이미지 도구 개선

## 확정 범위

- 대상: JWT, IP 네트워크, 웹 메타, 텍스트 추출, 텍스트 비교, 이미지 모자이크 6개
- 신규·통합 기능 3건: IPv4 주소의 정수·16진수·2진수 변환, WebPage JSON-LD 생성, 텍스트 비교의 변경 줄만 복사
- 개별 개선 6건: JWT 대표 클레임 요약, IP 5개 모드 셀렉트 전환, 메타 제목·설명 길이 판정, 추출 결과의 전체·고유·중복 수 표시, 텍스트 비교 빈 복사 보호, 모자이크 편집 단계·버튼 상태 표시
- 공통 수정 2건: 결과 없는 동작을 침묵시키지 않고 가까운 상태 문구로 안내, 결과 규모와 사용 판단 정보를 결과 안에 표시

## 실행 원칙

- 새 페이지를 늘리지 않고 기존 도구의 동일한 사용 맥락 안에 기능을 통합한다.
- 각 변경은 한국어·영어, 모바일 세로 화면, 클립보드 대체, iframe 높이 계약을 유지한다.
- 이 회차도 독립 커밋·푸시·Blogger 반영·공개 배포가 확인된 뒤에만 완료로 기록한다.

## Skill·Markdown 효율 개선

- 하드 수량을 고정 기능 목록으로 만들지 않고, 구현·검증된 증거의 경계만 Markdown과 기계 계획에 기록한다.
- 통합 기능을 허용하되 아이디어만 적거나 한 도구 수정 하나를 공통 수정으로 부풀리는 집계는 검증에서 거부한다.
